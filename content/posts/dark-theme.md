Одна строка `color-scheme: light dark` сообщает браузеру, что страница умеет
оба режима — и он сам подкрашивает скроллбары и элементы форм.

```css
:root { color-scheme: light dark; }

@media (prefers-color-scheme: dark) {
  :root { --bg: #0b0b0d; --fg: #f2f2f4; }
}
```

## Почему без переключателя

Системная настройка уже отражает то, что человек выбрал. Второй переключатель
на сайте спорит с ней и требует хранить состояние.

Если переключатель всё же нужен, его место — рядом с настройками аккаунта, а не
в шапке каждой страницы.
